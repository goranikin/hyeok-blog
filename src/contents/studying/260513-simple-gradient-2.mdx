In the previous post, I made a mistake. The tanh function is applied to
the last output value, so $y_pred$ is caught on [-1, 1].

I changed from
```python
a3 = torch.tanh(z3)

dL_dz3 = dL_dy_hat * (1 - a3**2)
```
to
```python
# remove
# a3 = torch.tanh(z3)

# identity
dL_dz3 = dL_dy_hat
```

If I don't use the normal distribution to generate random x and y values, the loss will seem to be wrong.
