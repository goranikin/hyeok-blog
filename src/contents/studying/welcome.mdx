(I skip the simpler chain rule warm-up)

---

Setup
- Three layers
- input dim = 4
- hidden dim = 8
- output dim = 3
- the tanh activation function

```python
d_in, d_h, d_out = 4, 8, 3

W1 = torch.randn((d_h, d_in)) * 0.5
W2 = torch.randn((d_h, d_h)) * 0.5
W3 = torch.randn((d_out, d_h)) * 0.5
```


$$
\begin{aligned}
a_1 = \tanh(W1x) \\
a_2 = \tanh(W2a_1) \\
\hat{y} = a_3 = \tanh(W3a_2)
\end{aligned}
$$

```python
# (d_in, ) -> (d_h, )
z1 = torch.matmul(W1, x)
a1 = torch.tanh(z1)

# (d_h, ) -> (d_h, )
z2 = torch.matmul(W2, a1)
a2 = torch.tanh(z2)

# (d_h, ) -> (d_out, )
z3 = torch.matmul(W3, a2)
a3 = torch.tanh(z3)
```

---

Our goal is to compute $\partial{L}/\partial{W_i}$ to update the parameters of $W_i$:
$$
W_i \leftarrow W_i - \alpha \partial{L}/\partial{W_i}
$$
Before writing down code, we should derive exact operations from partial derivatives.

For Case 1, it is reduced to the element-wise product form.  
For Case 2, it is hard to derive the vector's matrix partial derivative directly.
So we approach it from an element-wise perspective.

![gradient 3](/writing/backprop/gradient_3.png)
Given the two results above, we can write the expression $\partial{L}/\partial{W_{i, pq}}$.
It can be written as the sum of partial derivatives with respect to each $z_{i,j}$. But, why?
Let me walk through why that is.

For the single-variable case, the chain rule takes the simple form:
$$
\frac{dL}{dW} = \frac{dL}{dz}\frac{dz}{dW}
$$

However, an infinitesimal change $W_{i,pq}$ doesn't affect just one z. It changes all z components.
$$
dz_{i,j} = \frac{\partial z_{i,j}}{\partial W_{i,pq}}\, dW_{i,pq}, \quad \text{for each } j = 1, 2, \ldots, d_i
$$

L is a multivariable function.

$$
dL = \sum_j{\frac{\partial{L}}{\partial{z_{i,j}}}dz_{i,j}}
$$
Therefore,

$$
dL = \sum_j{\frac{\partial{L}}{\partial{z_{i,j}}}\frac{\partial z_{i,j}}{\partial W_{i,pq}}dW_{i,pq}}
$$

rewrite it:
$$
\frac{\partial{L}}{\partial{W_{i,pq}}} = \sum_j{\frac{\partial{L}}{\partial{z_{i,j}}}\frac{\partial z_{i,j}}{\partial W_{i,pq}}}
$$

After working through the algebra, $\partial{L}/\partial{W_i}$ can be expressed as the outer
product of $\partial{L}/\partial{z_{i,p}}$ and ${a_{i,q}}$.

By the result above, $\partial{L}/\partial{z_i}$ is equal to
$\partial{L}/\partial{a_{i}} \odot (1-{a_i}^2)$

$\partial{L}/\partial{a_i}$ is computed dynamically during the backward pass.
For the outermost layer, $a_3$ is equal to $\hat{y}$ and $\partial{L}/\partial{\hat{y}}$ can be calculated directly.

And that's it! Let's apply it to the problem.
